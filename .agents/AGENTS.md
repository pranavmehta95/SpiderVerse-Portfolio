# Project Rules

The following rules apply to all code modifications and feature development in this project.

1. Read the existing implementation completely.
2. Reuse existing components whenever possible.
3. Preserve the current visual identity.
4. Do not rewrite unrelated code.
5. Do not introduce duplicate logic.
6. Keep components modular.
7. Explain your implementation plan before writing code.
8. After completing a phase, stop and wait for approval before continuing.
